Decision Framework

Choose Option 1 if you want: Maximum transparency, immediate visibility of activity, social proof on homepage

Choose Option 2 if you want: Clean factor cards, centralized activity feed, blog-like recent updates

Choose Option 3 if you want: Minimal homepage changes, detailed history for engaged users, progressive disclosure

Option 1: Inline Git Info on Factor Cards

Shows last update time and recent contributors directly on each factor card.
Key differences:
  • Git info appears directly on homepage factor cards
  • Shows contributor avatars for social proof
  • Displays relative time (e.g., "2 weeks ago")
  • Visual status badges (UPDATED) for recently changed factors
  • Most information-dense approach
